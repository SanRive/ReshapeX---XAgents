                      THE WHOLE IDEA IN THREE SENTENCES

                      An AI agent is just a language model that you let take actions, not only
                      chat. You give it a goal and a few tools (things it can do, like search a
                      product catalog or call a company API), and it works in a loop: think, act,
                      look at the result, repeat, until the job is done.

                      Everything below is detail on those three pieces: the model, the tools,
                      and the loop. If you remember nothing else, remember that.

                 02   How an AI agent actually works
                      Simple or fancy, almost every agent runs the same loop. Once you see it, the
                      rest of the tools are just different ways to build each box.


                           1     You give it a goal + tools
                                 "Find the right replacement part for this discontinued model." Plus a
                                 tool: search the product catalog.

                                                                       ↓

                          2      The model thinks
                                 "To match a replacement I first need the specs of the old part."

                                                                       ↓

                          3      It uses a tool
                                 It calls search_catalog("old part number") . Your code runs it and
                                 returns the specs.

                                                                       ↓

                          4      It reads the result
                                 Now it has real data. It decides whether it needs another lookup or has
                                 enough to answer.


                                                 ↻ steps 2–4 repeat until the goal is met


                                                                       ↓

                          ✓      It answers
                                 "The matching part is X, because the specs line up. Here is the
                                 source." Grounded, not guessed.



                         Why this example, and why it matters here: the agents at this hackathon are
                         business tools for manufacturers and distributors, so being correct matters
                         far more than being clever. An agent that confidently invents a part number is
                         worse than useless. That is why almost every good B2B agent leans on tools
                         and real documents (steps 1 and 3) instead of trusting the model to just know
                         the answer.

                      D E FAU LT S TAC K


                      The quick-start stack
                      A minimal stack that gets an agent running quickly. Add a layer only when a
                      real problem forces you to.

                      MODEL                           Gemini free tier (or Groq for speed). Free, five-
                                                      minute signup, no credit card.

                      THE AGENT                       Start with plain function calling in the model's
                                                      SDK. Add an Agents SDK only if the loop gets
                                                      messy.

                      TOOLS                           Function calling for anything the agent needs to
                                                      do. Add MCP only if you want to reuse a tool
                                                      elsewhere.

                      KNOWLEDGE                       Only if you have documents → Chroma or
                                                      Pinecone + LlamaIndex. Otherwise skip it.

                      SEE WHAT HAPPENS                LangSmith, tracing on from the first run.

                      DEMO                            Streamlit or Gradio, run on your laptop.


                        In one line: get a free Gemini key, write a simple loop with function
                        calling, add documents only if you need them, and save the last ~35
                        minutes for a Streamlit demo.
